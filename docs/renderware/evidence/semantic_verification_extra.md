## Exact control conclusions retained by the tests

1. **FCMPO is tested as separate CR bits.** After an unordered comparison LT=GT=EQ=0, UN=1. Ramp lower clamp is LT-only; upper clamp is GT-only. Therefore unordered skips **both** clamps. Ramp enabled is `!(LT || EQ)`, so unordered selects enabled1 in this comparison-only scope, not a guessed NaN alpha. Normal nontrapping comparison completion is an assumption.
2. **Progress flags:** bit0 is active, bit2 inhibits, bit1 alone advances age. Clearing bit1 freezes age but not progress recomputation. Expiry is strictly `GT(age, FADDS(EPS,duration))`: equality stays active; expiry clears only bit0 and retains previous progress. Division is selected only by `GT(duration,EPS)`; ordered `duration <= EPS` and unordered take fallback1. Upper clamp is GT-only, with no lower clamp. A NaN quotient remains NaN; NaN duration takes fallback1 absent expiry/trapping.
3. **Interpolation:** interpolate only on LT against `0.9998999834060669`, not against 1. Equality, above-threshold, and unordered copy the target unchanged (including its non-normalized enable byte). Below cutoff, enabled is normalized OR of the two nonzero enable predicates. Disabled endpoints do not have their alpha forcibly zeroed. Equal alpha bypasses conversion. Scalar mixing is `FMADDS(target,t,FMULS(saved,FSUBS(1,t)))`, not an algebraically rearranged lerp.
4. **Fused witness:** saved=`3F89BED7`, target=`3F1C98E2`, t=`3E341532` produces `3F7E9501` in each of scale/aux08/aux0c. Both split multiply/add and the ordinary lerp rewrite produce `3F7E9500`. This is a reproducible one-ULP static arithmetic distinction, not a C++/console trace.

## Explicit limitations

- These tests do **not** execute the reconstructed C++, bind SDK callbacks, run an emulator/game, validate ABI/prologues, create textures, perform GPU work, prove EFB alpha/write-mask state, or establish source/binary/compiler equivalence. The workspace's parallel source integration is untouched.
- The scalar utility is not a full instruction interpreter for all controlling functions. Full progress-leaf control is interpreted; ramp arithmetic/prefix/flag slices and the interpolation interior are separately seeded. Their caller conditions, manager cast/resource-kind dispatch, intervening effects, actual setter invocation, target finalization, live timer/flag writers, allocation, and scheduling are not connected into an end-to-end execution claim.
- Nearest/ties-even single arithmetic is assumed for tested finite values. Live FPSCR rounding mode, exception/trap enables, exception flags, denormal hardware policy, signaling-vs-quiet NaNs, NaN payloads, and XER carry/SO are not modeled. No claim is made that FCMPO necessarily completes when traps are enabled.
- `FCTIWZ` models only the observed low integer word for conservative finite signed-32-range inputs. Actual alpha-conversion fixtures remain in `[0,255]`. Its high stored word is intentionally unavailable, not initialized to invented PPC bits. `T:803-812` asserts rejection of NaN, both infinities, and out-of-range values, and failure on an attempted high-word read. These are **scope-guard tests**, not emulated invalid-conversion results/FPSCR tests. The host truncation rule is never used to fabricate those unsupported PPC outcomes.
- References share elementary arithmetic primitives with the decoder. Raw dispatch/operand/memory/branch checks and fixed negative controls add independent grounding, but do not turn the Python model into a hardware oracle or automatically test future C++ edits.
- No blockers or test failures remained. A read-only `git status --short -- <two owned paths>` attempt returned `fatal: not a git repository`; no VCS diff is available for this extracted workspace. Ownership is established by the actual two-file edit/write ledger, not a fabricated clean Git status.
