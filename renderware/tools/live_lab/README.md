# RenderWare live lab source

This directory preserves the authored v0.8 Python inspector and its parameter
and object catalogs. It was used to observe RenderWare, stage and effect state
in Dolphin; the catalogs include addresses and partially understood fields.
Its behavior is an investigation tool, not reconstructed game runtime code.

The tool can write emulator memory and install a modified DOL. It is not run
by this repository's build or tests. No patched DOL, original game data,
screenshots or local process captures are published here. See
`README_v0_8.md` and `CHANGELOG_v0_8.md` for the preserved version notes.
